# TechNova Solutions – Enterprise Network Design & Implementation

## Project Overview
This project focuses on designing and implementing an enterprise network infrastructure for TechNova Solutions using Cisco Packet Tracer.

## Technologies & Networking Concepts
- Cisco Packet Tracer
- IPv4 VLSM Subnetting
- IPv6 Dual-Stack
- VLAN Configuration
- Inter-VLAN Routing (Router-on-a-Stick)
- OSPFv2 (Single-Area & Multi-Area)
- NAT/PAT
- DHCP & DHCP Relay
- Layer 2 Security
- Port Security
- BPDU Guard
- DHCP Snooping
- WPA2 Wireless Security

## Network Features
- Department-based VLAN segmentation
- Enterprise network connectivity between HQ and Branch Office
- IPv4 and IPv6 network design
- Dynamic routing using OSPF
- Network security configurations
- DHCP-based IP address allocation
- Secure wireless network
- Network troubleshooting and verification

## Project Files
- `TechNova_Final_Network.pkt` – Cisco Packet Tracer network simulation
- `ANE_TechNova Solutions.docx` – Project documentation and report
